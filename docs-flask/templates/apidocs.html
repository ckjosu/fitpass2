Probar la API

Aquí se puede ejecutar cada ruta de la API y ver la respuesta real. Las peticiones van a {{ api }}.

  1. Abre POST /api/auth/login, da clic en Try it out, escribe correo y contraseña y da Execute.
  2. Copia el token de la respuesta.
  3. Da clic en Authorize, pega el token y acepta.
  4. Ya puedes probar las rutas con candado, por ejemplo GET /api/gimnasios/mios.

Ojo: si la API es la de producción, las rutas POST, PUT y DELETE cambian datos reales. Para la expo usa rutas GET o la API local.
