# fitpass2

Proyecto del equipo TacoCoders.

## Ramas

- `main`: versión estable. Solo se actualiza con Pull Request aprobado.
- `dev-josue`: rama de trabajo de josue
- `dev-erick`: rama de trabajo de erick
- `dev-luis`: rama de trabajo de luis
- `dev-mauricio`: rama de trabajo de mauricio
- `dev-tommy`: rama de trabajo de tommy
- `historias-de-usuario`: una historia de usuario por cada pantalla.
- `practicas`: prácticas de la materia.

## Cómo trabajamos

1. Cada quien trabaja solo en su rama `dev-nombre`.
2. Al terminar una tarea se sube la rama y se abre un Pull Request hacia `main`.
3. Otro integrante revisa el código. Si lo aprueba, se hace el merge a `main`.
4. El avance de cada integrante se lleva en el tablero (Projects) del repositorio.
