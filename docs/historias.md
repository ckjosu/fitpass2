# Historias de usuario

Las historias de usuario y las tareas del equipo están en el tablero de GitHub Projects:

**[Tablero Gymred en GitHub Projects](https://github.com/users/ckjosu/projects/5)**

| Columna | Qué tiene |
|---|---|
| Todo | Tareas que todavía no empiezan |
| En progreso | Lo que se está haciendo ahora |
| Hecho | Lo terminado |
| Historias de usuario | Las historias (HU-01, HU-02…) |

Cada tarjeta es un *issue* del repositorio, con su responsable y su estado. Los nombres
indican el sprint y la parte del sistema: `S1-API` es sprint 1 de la API y `S2-WEB` es
sprint 2 del panel web.
