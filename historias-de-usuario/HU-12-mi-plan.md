# HU-12: Mi plan / contrato

**Pantalla:** Mi plan / contrato
**Plataforma:** Web (Angular) - Panel del dueño
**Responsable:** Josue
**Prioridad:** Baja
**Estado:** Pendiente

## Historia
Como **dueño de gimnasio**, quiero **ver el plan de contrato que tengo con la plataforma** para **saber qué funciones incluye y cuándo vence**.

## Justificación
Cada gimnasio se administra según su contrato (básico o premium). El dueño debe saber qué plan tiene, qué incluye y cuándo vence para no perder funciones.

## Criterios de aceptación
- [ ] Muestra el plan actual (básico o premium), su fecha de inicio y de vencimiento.
  - *Por qué:* Es la información básica del contrato.
- [ ] Muestra qué funciones incluye cada plan.
  - *Por qué:* El dueño entiende por qué algunas opciones no le aparecen y qué gana si cambia.
- [ ] Tiene un botón para solicitar cambio de plan.
  - *Por qué:* Si el gimnasio crece, puede necesitar un plan mayor.
- [ ] Si el plan está por vencer muestra un aviso.
  - *Por qué:* Evita que el gimnasio deje de aparecer en la app sin que el dueño se dé cuenta.
