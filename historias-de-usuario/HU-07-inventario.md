# HU-07: Inventario del gimnasio

**Pantalla:** Inventario del gimnasio
**Plataforma:** Web (Angular) - Panel del dueño
**Responsable:** Josue
**Prioridad:** Alta
**Estado:** Pendiente

## Historia
Como **dueño de gimnasio**, quiero **registrar el equipo y áreas que tiene mi gimnasio** para **que los socios sepan qué ejercicios pueden hacer aquí**.

## Justificación
No todos los gimnasios tienen el mismo equipo. Con el inventario, la app le muestra al socio qué ejercicios puede hacer según el gimnasio al que vaya.

## Criterios de aceptación
- [ ] Puedo agregar, editar y eliminar equipo (nombre, categoría, cantidad).
  - *Por qué:* El equipo cambia con el tiempo: se compra, se da de baja o se mueve.
- [ ] Cada equipo se relaciona con los ejercicios que se pueden hacer con él.
  - *Por qué:* Esa relación es la que permite armar la lista de ejercicios disponibles en la app.
- [ ] Tiene un buscador y filtro por categoría (cardio, pesas, máquinas, etc.).
  - *Por qué:* Un gimnasio puede tener mucho equipo y buscarlo a mano sería lento.
- [ ] La lista de ejercicios disponibles se actualiza en la app móvil.
  - *Por qué:* Es el objetivo principal de esta pantalla.
