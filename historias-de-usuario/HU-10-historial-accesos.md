# HU-10: Historial de accesos

**Pantalla:** Historial de accesos
**Plataforma:** Web (Angular) - Panel del dueño
**Responsable:** Josue
**Prioridad:** Media
**Estado:** Pendiente

## Historia
Como **dueño de gimnasio**, quiero **ver quién entró a mi gimnasio y a qué hora** para **llevar el control de las visitas**.

## Justificación
El dueño necesita un registro de quién entra y cuándo para llevar el control de su gimnasio y aclarar cualquier problema con un socio. También sirve para revisar intentos de acceso denegados.

## Criterios de aceptación
- [ ] Muestra una tabla con nombre del socio, fecha, hora y resultado (permitido o denegado).
  - *Por qué:* Son los datos básicos de cada visita.
- [ ] Puedo filtrar por rango de fechas.
  - *Por qué:* El dueño suele revisar por día, semana o mes.
- [ ] Puedo buscar por nombre del socio.
  - *Por qué:* Para aclarar el caso de un socio en específico.
- [ ] La tabla tiene paginación.
  - *Por qué:* Con muchos registros la tabla sería lenta y difícil de leer.
